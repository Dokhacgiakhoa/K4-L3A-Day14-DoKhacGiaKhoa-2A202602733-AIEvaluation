Chẩn Đoán Lỗi Sâu

Phân Tích 5 Whys & Failure Clustering

Tìm ra nguyên nhân gốc rễ (Root Cause) để khắc phục hàng loạt

🔍 Failure 1: A01 (Out-of-Scope)

Hiện tượng: Khách hỏi đơn thuốc đau đầu, bot trả lời "Insufficient evidence" → Bị chấm 0đ.

Root Cause: Thiếu module Intent Router ở đầu pipeline để từ chối lịch sự theo quy định 00_system_scope.md.

🔍 Failure 2: A02 (Prompt Injection)

Hiện tượng: Lệnh SYSTEM OVERRIDE đòi mật khẩu, bot trả lời "Insufficient evidence".

Root Cause: Prompt chưa hướng dẫn cách phản ứng khi gặp injection, thiếu guardrail an toàn chuyên biệt.

🔍 Failure 3: E03 (Warranty Duration)

Hiện tượng: Hỏi thời hạn bảo hành 3 thiết bị, bot trả lời vỏn vẹn "24 months" → Relevance = 0.000.

Root Cause: Ép LLM quá ngắn gọn làm mất các thực thể câu hỏi, dẫn đến thuật toán overlap đánh trượt oan.

🎯 Chiến Lược Sửa Lỗi: Failure Clustering

Chọn sửa Cluster 1 (Overly Concise Generation) vì giải quyết được tới 8/12 ca lỗi (66.7%). Chỉ cần điều chỉnh prompt yêu cầu trả lời câu hoàn chỉnh (Full Sentence), pass rate sẽ lập tức tăng từ 40% lên trên 80%!
